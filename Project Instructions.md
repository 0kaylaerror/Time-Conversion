Time-Conversion Sep 28,2026

ITSC-1212 Introduction to Computer Science; Project 2: Time Conversion; complete 5 functions that convert a number of seconds into several non-conventional time units.

When you first run the driver file, you may see errors. This is expected. The driver depends on functions that you will implement in the time_conversion module.

A correct program will:

    allow the user to enter a whole number of seconds

    output:

        a description of a decasecond and the converted value

        a description of a jiffy and the converted value

        a description of a New York Minute and the converted value

        a description of a nanocentury and the converted value

        a description of a Snapchat Streak Day and the converted value
